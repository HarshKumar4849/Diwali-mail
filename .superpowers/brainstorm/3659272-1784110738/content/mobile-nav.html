Mobile Navigation Pattern

How should the nav work on phones?

A

Hamburger Menu

Three-line icon in header, slides open a drawer with all links. Classic web pattern, leaves full width for content.

B

Bottom Tab Bar

Icons with labels fixed at bottom of screen. Feels app-like. Always visible, easy thumb reach.

C

Responsive Bar

Horizontal nav that collapses links into a hamburger on small screens. Standard responsive pattern.
